# Key 归属查询设计说明

视觉基准：[key-pin-concept.png](./key-pin-concept.png)

## 界面约束

- 单页独立工具，不使用侧边栏，不增加无关导航。
- 页面唯一主任务是输入 API Key 或 Key ID 并返回 PIN。
- 顶部使用深海军蓝，主页面使用纯白和冷灰背景，主色为紫蓝色。
- 控件圆角 6px，边框清晰，阴影克制，保持集团后台工具的紧凑感。
- 所有真实文本和控件均由代码渲染；设计稿不作为页面背景使用。
- 完整 Key 默认掩码显示，不进入本地存储、URL 或最近查询记录；上游运维平台可能保留查询审计记录。

## 状态

- 默认：空输入，查询按钮不可用。
- 聚焦：输入框显示紫蓝色焦点边框。
- 查询中：按钮显示“查询中…”。
- 成功：显示 PIN、Key ID、匹配状态和复制按钮。
- 未找到：明确提示检查环境、Key 状态和输入值。
- 输入错误：仅接受 `pk-` 或 `key-` 开头的值。
