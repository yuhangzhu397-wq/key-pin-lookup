# 三分钟演示

## 准备

按仓库 README 启动本地 Mock 环境，不填写真实访问 Token、真实 API Key 或数据库密码。

## 演示路径

1. 输入 `key-demo-zjpt888`，查看返回的 PIN、Key 使用人和 PIN 归属人。
2. 换成 `pk-demo-zjpt888`，说明两种查询入口共享一致的结果结构。
3. 切换 TPM 总水位，说明容量、用量和水位的关系。
4. 查看下游监控，说明峰值窗口、配额对比和结果缓存。
5. 对照产品案例解释缺失映射、短前缀和空结果的处理方式。

## 解释重点

- PIN 与 ERP 对应关系依赖权威映射。
- TPM 水位是特定窗口的观察值；它与长期额度不是同一个指标。
- 公开演示数据是合成样例；实际生产环境必须配置鉴权和只读数据权限。
